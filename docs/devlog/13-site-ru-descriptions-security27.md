## 1. Окна «Жанр» и «Год»

`S.mvfilter(p)`: `movies/mvfilter:genre` — только жанры, `movies/mvfilter:year` — только годы; счётчики учитывают второй фильтр («с учётом жанра «Ужасы»»). Выбор сразу возвращает к каталогу. Дублирующий ряд жанров на вкладке убран. `A.go` теперь передаёт параметр любого экрана (`экран:параметр`). Стрелки ‹ › полок выровнены (inline-flex по центру).

## 2. Русские описания

`tools/build_movies.py`: Wikidata отдаёт не только русское название, но и статью ру-Википедии (`schema:about … isPartOf ru.wikipedia`); `wiki_ru_intro()` берёт первые предложения статей (API `prop=extracts`, по 20 за запрос). В карточке — `dr` (текст) и `wa` (статья). Совпадение — **строго по году ±1** (раньше было и «без года» — так фильму 2026 года досталось описание фильма 2017-го). Итог: ≈480 фильмов с русским описанием, ≈590 с русским названием.

В приложении `filmDesc()`: русское описание + «Описание: Википедия, CC BY-SA 4.0» (ссылка на статью, как требует лицензия); если русской статьи нет — описание прокатчика и «Перевести на русский ↗» (Google Переводчик в браузере).

**«Сам фильм» не добавлен:** новые фильмы законно показывают только онлайн-кинотеатры по подписке/покупке; бесплатных легальных копий нет, а пиратские источники проект не использует. Остаются официальный трейлер и «Где смотреть»; бесплатно в приложении — фильмы общественного достояния.

## 5. Сайт

Корневой `index.html` на GitHub Pages — https://kyranashi.github.io/bridgetv/ : определяет устройство и даёт одну главную кнопку, ниже — все платформы, «Открыть в браузере», «Как проверить, что файл настоящий». `web/install.html` перенаправляет туда (старые ссылки работают). Ссылка на сайт — первой строкой README и в приложении (Ещё → «Установить на другие устройства»).

Безопасность сайта: только свои скрипты и картинки (CSP `default-src 'none'`), без сторонних библиотек, шрифтов и счётчиков, без форм и cookies; адреса скачивания собираются из зашитого списка файлов (`FILES`), а не из страницы или адреса; защита от встраивания в чужой сайт (frame-busting — GitHub Pages не даёт задать `X-Frame-Options`); HTTPS и HSTS — от GitHub Pages; `/.git`, `/.env`, исходники инструментов — 404 (проверено).

## 6. Фильмы, которые можно смотреть

- Раздел «▶ Можно смотреть бесплатно» сразу под «Новинками»: официальные каналы киностудий (лента `classic`: Мосфильм, Беларусьфильм — полные фильмы от правообладателей, официальный плеер YouTube) и полки общественного достояния (archive.org). Ниже — «🎬 Каталог по жанрам».
- `TV.arch.findFilm(название, год)` — для фильмов каталога до 1970 года ищет полную версию в общественном достоянии; найдено — на странице фильма кнопка «▶ Смотреть фильм бесплатно».
- **Важно:** первая версия поиска нашла в архиве «Доктора Стрейнджлава» и «Маньчжурского кандидата» — это охраняемые фильмы, загруженные посторонними. Поэтому принимаются только записи с явной пометкой `licenseurl …/publicdomain/…` (проверка: «Ночь живых мертвецов» 1968 — находится, «Доктор Стрейнджлав» — нет).

## 6a. «Новинки бесплатно» и поиск видео без ключа (правки по отзыву)

**Новинки бесплатно.** Проверены официальные каналы, о которых пишут как о «бесплатных фильмах»: Warner Bros. выкладывает только трейлеры и первые 10 минут, «Русские фильмы» — короткие ролики, канал с именем Star Media оказался чужим, FILM.UA — украинские сериалы. Надёжного законного источника бесплатных *новых* полных фильмов нет. Поэтому «новинки» в разделе «Можно смотреть бесплатно» — это **новые поступления** общественного достояния: `TV.arch.shelves` → `fresh` (сортировка `addeddate desc`, `TV.arch.query(…, sort)`). Пометку public domain ставит загрузивший, и среди свежих записей встретились гонконгские боевики 1980-х — поэтому ещё и год выхода до 1964 (то же ограничение — в `findFilm`).

**Видео без ключа.** Получать результаты поиска YouTube без API (разбор страниц, подмена клиента) нельзя — это обход защиты YouTube. Поэтому `TV.yt.openSite(url)`: ПК — новая команда моста `ytwin` → `openYouTube()` в `desktop/main.js` — отдельное окно с сайтом YouTube: своя сессия `persist:youtube` (cookies не смешиваются с приложением), песочница, без preload/моста, переходы только на YouTube и вход Google (`YT_HOSTS`), остальное — во внешний браузер, разрешения — только полноэкранный режим. Android — системная ссылка открывает приложение YouTube. Браузер — новая вкладка.

**Ключ Android.** Ключ загружен, но пароль в секрете не подходил (сборка упала: «keystore password was incorrect»). Пароль из `PASSWORD.txt` ключ открывает (проверено локально, без вывода) — в секрет попала лишняя часть строки. `android.yml` теперь проверяет пароль `keytool -list` до сборки: не подошёл — подпись прежним отладочным ключом и предупреждение в отчёте; в `docs/ANDROID.md` — команда, которая берёт из файла только сам пароль.

## 7. Свой адрес сайта

bridgetv.org и bridge-tv.org заняты (RDAP). Свободны bridgetv.app, .net, .tv, .online; бесплатно — bridgetv.js.org. Подготовлено: переменная репозитория `SITE_DOMAIN` → `pages.yml` кладёт `CNAME`; `TV.PAGES_ORIGINS` — плеер YouTube доверяет и старому, и новому адресу. Шаги — `docs/SITE.md`.
