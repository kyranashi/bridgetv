# 15. Версия 1.4.0 — быстрее, проще, без ключей (17.11.2026)

**Зачем.** Тест 1.3.0: на iPad mini 1 каналы грузятся долго, «Видео» и фильмы Rutube не работают; на Xiaomi и Honor ТВ медленный и зависает; лёгкий режим слишком сложный.

**Что сделано (каждый шаг — своя ветка, цепочкой):**
1. `fix/ipad-lite` — свои SVG-значки вместо символов (на iOS 9 — квадратики), кнопки без градиента, на iOS 9–11 скрыто то, что там не работает.
2. `feat/films-split` — «Фильмы / Сериалы», сериал одной карточкой, студии фильтром, без повторов.
3. `perf/fast-start` — «гонка» источников (проверка двух следующих, переход на ответивший), старт с лёгкого качества.
4. `feat/video-nokey` — подборки «Видео» и «Популярное за 3 дня» без ключа (`tools/build_ytfeeds.py`), окно YouTube на Android.
5. `fix/android-speed` — hls.js на Android, отдельная очередь моста для фоновой проверки, проверка мягче.
6. `feat/simple-mode` — простой режим: ТВ / Фильмы / Избранное / Ещё, крупные плитки, автозапуск последнего канала.
7. `feat/kino-tv` — «Кино по ТВ — сейчас в эфире» и бесплатные mp4 для iOS 9.
8. `perf/light-data` — `data/epg-lite.json` (~410 КБ вместо ~1 МБ).
9. `feat/player-extras` — «Не работает», таймер сна, «Медленный интернет».
10. `feat/tv-continue` — Android TV: ряд «Продолжить» (`WatchNext.java`, ссылка `bridgetv://play/<id>`).
11. `feat/yt-search-proxy` — заготовка общего поиска YouTube (`server/yt-proxy`, выключено до ключа владельца).
12. `feat/more-studios` — официальный канал СТВ на Rutube.

**Проверка.** В браузере с имитацией iPad/Android; сборки всех платформ в CI; тестовый выпуск `test-1.4.0`.
**Не сделано / решения владельца:** обход YouTube/Rutube отклонён (защита сервисов, риск блокировки); поиск YouTube для всех — после ключа владельца на сервере; Rutube на iOS 9 не работает (нужен новый движок браузера).
