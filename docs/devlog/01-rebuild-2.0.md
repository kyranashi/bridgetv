# Шаг 01 — Пересборка в полноценное приложение (0.2.0)

**Запрос.** Из первой версии (нативный список каналов на Objective-C для iPad mini 1) сделать полноценное приложение: интерфейс «чистого ТВ», поиск как на YouTube, фильтр нерабочих каналов, избранное, YouTube, плеер для фильмов; РФ и РБ — основные, остальные страны — в «Дополнительно»; работа на разных платформах и на старой технике; документация.

## Решение
- **Один интерфейс для всех платформ** — `web/` (HTML/CSS/JS на ES5, без фреймворков: работает в Safari iOS 9, на ТВ и ПК).
- **iOS-оболочка** — `ios/src/main.m`: WKWebView показывает `web/` из ресурсов + мост для запросов в обход CORS и старых сертификатов.
- **Каталог каналов** — `tools/build_catalog.py` собирает открытый каталог iptv-org, `tools/check_streams.py` проверяет каждую ссылку «как iPad».

## Файлы
| Файл | Что внутри |
|---|---|
| `web/js/core.js` | утилиты, `TV.ajax`, хранилище `TV.store`, профиль устройства `TV.device`, настройки |
| `web/js/data.js` | каталог `TV.catalog`, «здоровье» ссылок `TV.health`, избранное, история |
| `web/js/services.js` | YouTube (Invidious/Piped), архив кино, фильмы с ПК |
| `web/js/player.js` | плеер с перебором источников |
| `web/js/nav.js` | пульт и клавиатура |
| `web/js/app.js` | экраны и навигация |

## Ключевая идея: перебор источников в плеере
```js
// web/js/player.js — tryVariant(): ждём источник settings.timeout секунд, иначе следующий
srcT = setTimeout(function () { if (state && !state.started) fail('таймаут ' + sec + ' с'); }, sec * 1000);
// fail(): тот же источник другим движком (встроенный HLS ↔ hls.js), потом следующий вариант
```
Подробно — [ARCHITECTURE.md](../ARCHITECTURE.md), раздел 2.4.

## Найдено по ходу
- iOS 9 не знает корневые сертификаты Let's Encrypt → «вечная загрузка». Решение: профиль `web/certs/*.mobileconfig` + свои корни в запросах приложения (`TVTrust` в `main.m`).
- Около трети ссылок открытого каталога мёртвые → статусы, «Только рабочие», раздел «Не работают».
