# Шаг 05 — Больше рабочих каналов (0.2.2)

**Запрос (по итогам теста на iPad).** Вкладка ТВ нравится, но большинство каналов не открывается. Хочется смотреть конкретные каналы (ТНТ и т.д.), а не искать, какие загрузятся. Нужно обновить списки, чтобы канал сам открывался с другой ссылки, если одна не работает.

## Почему каналов было мало — 3 причины

1. **Мало источников.** Каталог брал только выборку iptv-org «по стране канала» (`countries/ru.m3u`). Полный файл потоков (`streams/ru.m3u`) и другие открытые списки не использовались. У многих главных каналов была одна ссылка — умерла она, умер и канал.
2. **Проверка шла «из Лондона».** На ПК пользователя включён VPN (Psiphon), это подтвердил официальный API Первого канала (`"country":"GB"`). Многие каналы РФ отдают видео только внутри России, белорусские — только в Беларуси. Проверка с ПК помечала их мёртвыми, и приложение их прятало — хотя у пользователя (Беларусь, без VPN) часть из них работает.
3. **Устройство не проверяло каналы само.** Отметки «работает» появлялись только после попытки посмотреть.

## Что сделано

### 1. Новые источники и склейка ссылок одного канала — `tools/build_catalog.py`
| Источник | Что даёт |
|---|---|
| iptv-org `countries/<код>.m3u` + `streams/<код>.m3u` | объединение двух файлов, дубликаты ссылок отбрасываются (`fetch_country`) |
| iptv-org `languages/rus.m3u` | русскоязычные потоки каналов РФ/РБ + новый раздел «🗣 Русскоязычные (мир)» |
| [Free-TV/IPTV](https://github.com/Free-TV/IPTV) | курируемый список бесплатных каналов: ОНТ, СТВ, «Беларусь 4», СТС, ТНТ, Пятница!, Матч ТВ и др. (`fetch_freetv`) |

Ссылки одного канала из разных источников склеиваются **по названию**:
```python
def name_key(name):
    """«Россия-1 (1080p) Ⓢ» -> «россия1»; латинские двойники букв -> кириллица («Dомашний»)"""
    s = re.sub(r"\(.*?\)|\[.*?\]", "", name or "")
    if is_cyr(s):
        s = s.translate(LOOKALIKE)
    s = re.sub(r"[^0-9a-zа-яіў]+", "", s.lower().replace("ё", "е"))
    s = re.sub(r"(hd|sd|fhd|uhd|4k)$", "", s)
    return NAME_ALIAS.get(s, s)        # «первыйканал» -> «первый», «твц» -> «твцентр»…
```
`merge_by_name()` добавляет ссылки к найденному каналу как резервные варианты (до 8 у РФ/РБ), а если такого канала нет — создаёт его с категорией по названию (`guess_cat`). Сортировка «как на пульте» (`sort_region`) теперь понимает и кириллические названия (`RU_TOP`, `BY_TOP`).

### 2. Мягкая проверка для РФ и РБ — `tools/check_streams.py`
`python tools/build_catalog.py --soft ru,by`: канал РФ/РБ прячется, только если **все** его ссылки точно мертвы (нет домена, 404, DRM, только HEVC). «Не ответил из Лондона» — не повод прятать. Окончательно решает проверка на устройстве. CI (`.github/workflows/catalog.yml`) уже работает в этом режиме.

### 3. Проверка каналов на самом iPad — новый модуль `web/js/scan.js`
```js
// Проверить канал: варианты по порядку, до первого рабочего
function checkChannel(c, cb) {
  var vs = TV.health.variants(c), i = 0;
  (function next() {
    if (i >= vs.length) { cb(false); return; }
    var v = vs[i++];
    probe(v.u, function (ok) {           // скачать .m3u8 через нативный мост (без CORS)
      TV.health.mark(v.u, ok);           // запомнить: работает / нет — из СВОЕЙ сети
      if (ok) cb(true); else next();
    });
  })();
}
```
- `probe()` считает ссылку рабочей, если ответ начинается с `#EXTM3U` и в нём есть потоки (`#EXT-X-STREAM-INF` / `#EXTINF`). Заглушки «недоступно в регионе» отсеиваются.
- 3 параллельных запроса в лёгком режиме (iPad mini 1), 6 — в полном; таймаут 7–9 с.
- Пока открыт плеер, проверка стоит на паузе — не отнимает канал у видео.
- **Автоматически**: раз в сутки и после обновления каталога, через 20 с после запуска (`TV.scan.auto`). **Вручную**: «🔄 Проверить каналы» на вкладке ТВ и «Ещё → Проверить каналы на этом устройстве». Во время проверки виден прогресс «Проверка: 120 из 430 · работает 95».
- Результат идёт в `TV.health`: если ссылка ответила у вас, канал показывается, даже если проверка каталога считала его мёртвым. Если у вас не открылась ни одна ссылка — канал прячется в «Не работают».
- Только в приложении: браузер не даёт читать чужие плейлисты (CORS). В веб-версии остаётся запоминание при просмотре.

### 4. Автообновление каталога — `web/js/app.js`
`autoUpdate()`: раз в 2 дня приложение само скачивает свежий каталог с GitHub (тихо; сообщает, только если он действительно новее), затем запускает проверку на устройстве.

## Плеер (без изменений, напоминание)
При открытии канала плеер сам перебирает его ссылки: сначала те, что недавно работали на этом iPad, затем по проверке каталога. Каждой даётся 12 с (+4 в лёгком режиме), потом следующая. Чем больше ссылок у канала — тем выше шанс, что он откроется сам.

## Как проверить на iPad
1. Установить `releases/BridgeTV-0.2.2.ipa` поверх.
2. Открыть приложение, подождать ~20 с — начнётся проверка (прогресс на вкладке ТВ), или нажать «🔄 Проверить каналы».
3. После проверки на главной останутся только каналы, которые открываются именно у вас.
