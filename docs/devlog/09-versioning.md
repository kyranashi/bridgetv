# Шаг 09 — Схема версий (0.2.5)

**Запрос.** Нумерация `0.2.5`: 0 — основной полноценный релиз (пока разработка), 2 — глобальные обновления, 5 — мелкие правки; так и дальше.

## Сделано
- Все версии переведены: 2.5.0 → **0.2.5**, история — 0.1.0 … 0.2.4 (старые номера в скобках в `CHANGELOG.md`).
- `docs/VERSIONING.md` — схема, правила, алгоритм выпуска, таблица «было → стало».
- `tools/bump_version.py patch|minor|major|X.Y.Z` — меняет версию во всех местах: `TV.VERSION`, `kAppVersion`, `Info.plist` (версия, CFBundleVersion +1), `android/app/build.gradle` (versionName, versionCode +1), README.
- Номера сборок только растут: iOS CFBundleVersion 8 → 9, Android versionCode 250 → 251 — обновление ставится поверх старой «2.5.0».
- GitHub: релиз **v0.2.5** (собран заново, версия внутри — 0.2.5), релиз v2.5.0 удалён как заменённый, у v2.3.0 / v2.4.0 обновлены названия.
