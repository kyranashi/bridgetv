# 10. Официальный YouTube, новинки, ПК и PWA, безопасность (0.3.0)

**Дата:** 11.11.2026 · **Версия:** 0.3.0 (глобальное обновление)

## Что просили

- Фильмы не загружаются: «YouTube недоступен: HTTP 500», «Видео не открылось (таймаут)».
- Новый дизайн и новая иконка; убрать синюю обводку при нажатии на вкладки, сделать плавнее.
- Одно приложение для всех платформ, в том числе ПК («буквально везде одним разрешением»), размер — до 100 МБ.
- Больше жанров (аниме и др.), **новинки** (не зацикливаться на Мосфильме), приложение само понимает, что устройство может воспроизвести.
- Безопасность — по максимуму (одобрены все варианты), правовой и security-аудит, никакого запрещённого контента и плагиата.
- Убрать лишнее с GitHub, оставить только свежее; локальные файлы и историю сохранить на ПК.

## 1. Почему не грузились фильмы и что сделано

Все публичные зеркала Invidious/Piped в ноябре 2026 перестали отдавать видео (проверено: 6 из 6 отвечают 403/500/таймаутом). Обходить защиту YouTube подменой клиентов проект не будет. Решение — **совместить официальный путь со своим зеркалом**, выбор по устройству (`web/js/services.js`):

```js
mode: function () {
  var src = TV.settings.ytSource || 'auto', mirror = mirrorList().length > 0;   // auto | official | mirror
  if (src === 'mirror') return mirror ? 'mirror' : 'none';
  if (src === 'official') return 'official';
  if (embedOk()) return 'official';
  return mirror ? 'mirror' : 'none';                  // iOS < 12, Android < 5 — только своё зеркало
},
```

- **Официальный плеер** — `web/yt.html`: YouTube IFrame API на youtube-nocookie.com. Страница принимает только `v` из 11 символов `[\w-]` и сообщает приложению `ready/playing/paused/ended/error`. Лежит на GitHub Pages: YouTube требует настоящий Referer, а у `file://` его нет.
- `player.js: playEmbed()` вставляет `iframe.p-embed`, ждёт `ready` 30 с, переводит коды ошибок (101/150/152/153 — «YouTube не разрешил показ…», 100 — удалено). Обработчик `message` принимает события только от своего origin или GitHub Pages.
- **Данные:** YouTube Data API v3 с ключом пользователя (`apiCached()` — кэш 6 ч в `ytc_<ключ>`; поиск 100 ед., остальное 1 ед.), **RSS-ленты** официальных каналов без ключа (`channel()` → `rss()`; в браузере не работают из-за CORS, в приложениях — через мост).
- Экран «🔑 Ключ YouTube API» с пошаговой инструкцией, ссылками на Условия YouTube и Политику Google.

## 2. Новинки, жанры, возможности устройства

- `TV.yt.feeds` — подборки: «🆕 Новинки кино — трейлеры и премьеры» (Central Partnership, Кинопоиск, Netflix, Universal, Disney), «🧸 Новые мультфильмы», «🌸 Аниме» (Muse Asia, Crunchyroll, Aniplex, GKIDS), «🎞 Классика». id каналов проверены по RSS. Фан-каналы с пиратскими загрузками исключены. `TV.yt.feed()` сливает ленты и сортирует по дате.
- Полки поиска (с ключом): «🆕 Новинки кино 2026», «🎟 Трейлеры премьер», «📺 Новые сериалы» — первыми.
- `films.js`: жанры + аниме, триллер, фэнтези, семейные, исторические, биография, мюзикл, спорт, сериалы.
- `core.js: TV.caps` — `canPlayType`/`MediaSource.isTypeSupported` для H.264, HEVC, VP9, AV1, WebM, MKV, HLS и `maxH`. `TV.caps.file(name)` решает, можно ли сыграть файл с ПК. Настройки → «Ваше устройство» показывает таблицу.

## 3. Дизайн и иконка

- `tools/make_icons.py` — **своя** иконка: градиент индиго → бирюза, белый «экран», кнопка Play и подставка-«мост». Генерирует все размеры: iOS, Android (+ баннер Android TV), веб (192/512/маскируемая/фавикон), Windows `.ico`.
- `app.css` — блок «Дизайн 0.3.0»: градиент активных элементов, радиусы 16 px, размытие шапки, нажатие `scale(0.97)`, индикатор вкладки, плавное появление экрана (`#main.anim`).
- **Синяя обводка:** правила фокуса теперь только для `html.kbd`. `nav.js: setKbd()` включает класс при нажатии клавиш/пульта и снимает при касании/мыши — на сенсорных экранах обводки нет, на ТВ и с клавиатуры фокус виден.

## 4. Одно приложение везде

- **Программа для ПК** (`desktop/`, Electron): своя схема `bridgetv://app/`, мост `window.TVBridge` (как у Android). `core.js` теперь работает с любым синхронным мостом:

```js
TV._bridge = window.TVAndroid || window.TVBridge || null;
if (TV._bridge && !window.TV_NATIVE) {
  window.TV_NATIVE = JSON.parse(TV._bridge.info());     // {platform:'desktop', …}
  window.TV_SAVED = JSON.parse(TV._bridge.saved() || '{}');
}
```

- **PWA:** `web/manifest.json` (иконки, standalone), `web/sw.js` (интерфейс из кэша, каталог — сначала сеть, чужие адреса не трогаются).
- **Страница установки** `web/install.html` — определяет устройство по User-Agent, ставит нужную карточку первой, ссылки `releases/latest/download/<имя>` (имена файлов без версии).
- CI: `.github/workflows/desktop.yml` (Windows: установщик + переносная; Linux: AppImage). Подробно — [DESKTOP.md](../DESKTOP.md).

## 5. Безопасность

| Где | Что |
|---|---|
| `web/index.html` | CSP: скрипты только свои (`'self' file: bridgetv:`), без eval, `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`, фреймы — только свои, GitHub Pages и YouTube |
| `data.js: TV.catalog.valid()` | скачанный каталог принимается, только если списки нужной формы и все ссылки — http/https |
| `ios/src/main.m` | `TVIsWebURL`/`TVWebURLFrom`; команды только от главного фрейма; GET/POST; главная страница не уходит на чужие сайты; внешние ссылки только http/https |
| `Bridge.java`, `MainActivity.java` | `isWeb()`, лимиты (команда ≤ 200 КБ, ответ ≤ 32 МБ, запись ≤ 8 МБ), таймауты 1–120 с, отладка WebView выключена, геолокация и сохранение форм выключены |
| `desktop/main.js` | песочница, Fuses, `inside()` против выхода из папки, запрет разрешений и навигации, CSP-заголовок |
| CI | действия по SHA, `persist-credentials: false`, attestation (`actions/attest-build-provenance`), `checksums.yml` (SHA256SUMS), `codeql.yml`, `dependabot.yml` |
| Документы | `SECURITY.md`, `docs/PRIVACY.md`, `docs/AUDIT.md` (законы рынков, магазины, MASVS, риски, план), раздел 10 в `LEGAL.md` |
