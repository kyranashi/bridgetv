# 12. «Фильмы» — каталог как в онлайн-кинотеатре, «Видео» — тренды YouTube (1.1.0)

**Дата:** 11.11.2026 · **Версия:** 1.1.0

## Что просили

«Вкладку Видео раздели со вкладкой Фильмы: в одном показывай тренды YouTube, во втором — как на Кинопоиске; фильмы не перемешивай и добавь, чтобы сначала новые показывало».

Образец — Кинопоиск (каталог с постерами). Пиратские сайты как источник не используются: только официальные данные, официальные трейлеры и ссылки на легальные кинотеатры.

## Источник каталога — `tools/build_movies.py`

1. **Каталог Apple (iTunes RSS)** — топ фильмов США по 15 жанрам (до 200 в каждом) → ≈1235 фильмов; топ России — фильмы с русскими названиями.
2. **iTunes Lookup API** (порциями по 150 id) — дата выхода, жанр, описание, возрастной рейтинг, длительность, режиссёр, постер (меняем размер в адресе на 300×450) и **официальный трейлер** (`previewUrl`, mp4 H.264 — играет даже на iOS 9).
3. **Wikidata** — русские названия: запрос `VALUES ?en {…}` порциями по 60 точных английских названий (общий запрос по всем фильмам за годы падал по таймауту). Совпадение с учётом года ±1. Русское название есть у ≈ половины.
4. Сортировка по дате — **новые первыми**. Файл ≈1,2 МБ публикуется на GitHub Pages раз в день (`pages.yml`), в репозиторий не коммитится.

## Приложение

- `films.js: TV.movies` — `load()` (свой сервер → GitHub Pages, в памяти, 12 ч), проверка записей (только https-адреса), `find({q, genre, years})`, `item()` (карточка `k:'mv'`), `where()` (Кинопоиск, Apple TV, Иви, Google). В детском режиме — только семейные с рейтингом G/PG.
- `app.js: S.movies` — поиск, фильтры жанр/год, «🆕 Новинки» (художественные), полки по жанрам (≥ 4 фильмов), «— бесплатно» (общественное достояние), инструменты (Google, загрузки, ПК, ссылки). С фильтром — сетка постеров `.ps`, новые первыми.
- `S.film` — страница фильма: постер 600×900, факты, описание, «▶ Трейлер» (плеер, элемент `k:'tr'` — не скачивается и не попадает в «Продолжить»), «Где смотреть», «Похожие».
- `mvCard()` — постер 2:3, `loading="lazy"`: без этого браузер ставил в очередь сотни постеров со всех полок, и постер на странице фильма не успевал загрузиться.
- Поиск (вкладка «Поиск» → «Фильмы») — каталог + общественное достояние.

## Выбор жанра (правка по отзыву)

Ряд жанров не помещался на экран, а на ПК его нельзя было пролистать мышью. Сделано и то, и другое:
- `S.mvfilter` — окно «🎭 Жанр и год»: все жанры и годы сразу (крупные кнопки, переносятся по строкам), рядом с каждым — сколько фильмов найдётся; счётчики пересчитываются при выборе; «Показать N фильмов» возвращает к каталогу. На вкладке — кнопки «🎭 Жанр: … ▾», «📅 Год: … ▾», «✕ Сбросить». `TV.plural()` — «1 фильм / 2 фильма / 5 фильмов».
- `scrollRows()` — все горизонтальные ряды (`[data-shelf]`: жанры, полки) на ПК листаются колесом мыши, перетаскиванием (после перетаскивания карточка не «нажимается») и стрелками ‹ › (`A.rowStep`), которые видны только без сенсорного экрана.

## «Видео» — только YouTube

`TV.yt.shelves`: «🔥 В тренде на YouTube» первым, «📰 Новое: новости и события», аниме, мультфильмы, музыка (свежее — `sort: upload_date`)… Убраны «Новинки кино», «Трейлеры премьер», «Фильмы целиком». Подборки RSS во «Видео»: мультфильмы и аниме (трейлеры кино и киностудии — нет).
