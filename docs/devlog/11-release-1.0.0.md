# 11. Полноценный релиз 1.0.0: программа передач, эфир, серии, родительский контроль

**Дата:** 11.11.2026 · **Версия:** 1.0.0 (первый полноценный релиз)

## Что просили

«Размер — как будет лучше, лимитов нет. Добавь это (план следующих версий), проведи тесты по всем направлениям, распиши итоги и давай сделаем окончательный релиз полноценного приложения». План: программа передач, перемотка эфира, автопереход к следующей серии, родительский контроль, крупный шрифт, перенос избранного, голосовой поиск на Android TV.

## 1. Программа передач (EPG)

- `tools/build_epg.py` — скачивает открытый XMLTV-гид epg.pw (`epg_RU.xml.gz`, ≈120 МБ в распакованном виде), разбирает его потоково (`ElementTree.iterparse` + `el.clear()`, память не растёт), сопоставляет каналы с каталогом по названию тем же `name_key()`, что и при сборке каталога (с отбрасыванием «HD» и часовых сдвигов «+2/+4», плюс `ALIAS` для «СТВ Беларусь», «Матч!»). Окно −2…+30 часов. Результат: ≈290 каналов, все 27 главных РФ и РБ.
- Файл не коммитится: `.github/workflows/pages.yml` собирает его **каждый день** (cron) и публикует на GitHub Pages. Если гид недоступен — сайт всё равно публикуется (`continue-on-error`).
- `data.js: TV.epg` — `load()` (сначала свой сервер, потом GitHub Pages; держится в памяти, обновляется раз в 6 ч), `list(id)`, `now(id)` → `{cur, next, pct}`. В localStorage не пишется — на iPad mini 1 не хватило бы места рядом с каталогом.
- `app.js: epgNow()` — строка «что идёт» на карточке канала; `player.js: chSub()` — «Сейчас: … (до 23:00) · Далее: …», `openGuide()` — панель 📋 с программой по дням (названия дней без `Intl` — его нет в Safari iOS 9).

## 2. Перемотка эфира

`player.js: dvrWindow()` смотрит `video.seekable`: если трансляция хранит больше минуты, плеер получает класс `dvr` (видны «−30» и пауза), а если зритель отстал от эфира больше чем на 20 с — `behind` (красная «В эфир»). `P.seek()` для эфира двигает в пределах окна (◀ ▶ пульта).

## 3. Следующая серия

`nextSoon()` — на `ended` (и на событие `ended` официального плеера YouTube) показывает «Далее: … — через 5 с» с кнопками «Смотреть сейчас» / «Отмена», затем `P.step(1)`. Последний элемент списка не зацикливается. Настройка `nextEp`.

## 4. Родительский контроль и крупный текст

- `TV.blocked()` в детском режиме скрывает все телеканалы, кроме категории `kids` — это сразу действует на списки, поиск, «Продолжить» и номера.
- `feedsList()`, `archList()`, `ytSearchShelves()` оставляют только детские подборки; поиск YouTube — `safeSearch=strict`.
- PIN (4 цифры) обязателен для включения; в детском режиме Настройки открываются только по PIN (`pinGate()`, экран `S.pin`), кнопка «Выйти (PIN)» на вкладке ТВ.
- Размер текста: класс `font115`/`font130` на `<html>` и `zoom` для `#app` — масштабируется весь интерфейс одинаково (свойство `zoom` есть и в Safari iOS 9, и в браузерах ТВ).

## 5. Перенос избранного

`exportBackup()` → `BTV1:` + base64(JSON) с `fav`, `subs`, `links`, `playlists`, `searches`, `pos` и настройками (без ключа YouTube, PIN и детского режима). `importBackup()` проверяет префикс, размер, `app: 'BridgeTV'`, типы значений и берёт только известные настройки (`TV.defaults`). Без сервера: код копируется или сохраняется файлом.

## 6. Голосовой поиск

- Android/Android TV: `Bridge.java` сообщает `voice: SpeechRecognizer.isRecognitionAvailable()`, команда `voice` → `MainActivity.startVoice()` (`RecognizerIntent`, ru-RU) → `onActivityResult` → `TV.nativeEvent('voice', {text})`. В манифесте — `<queries>` для Android 11+.
- Браузеры: Web Speech API (`SpeechRecognition`/`webkitSpeechRecognition`). В программе для ПК кнопки нет (в Electron распознавание Google не работает без ключа).
- Распознанный текст уходит в обычный поиск (`TV.on('voice')`).

## 7. Размер программы для ПК

Лимита больше нет — оставлено как лучше для пользователя: максимальное сжатие и только русская/английская локаль Chromium (остальные языки интерфейса Chromium не нужны). Electron закреплён на исправленной ветке `^45.3.0` (Dependabot показывал 44 уязвимости из-за слишком широкого диапазона `>=38`).
