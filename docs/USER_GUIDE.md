# Руководство пользователя

**Установка на любое устройство** — страница https://kyranashi.github.io/bridgetv/web/install.html (или в приложении: Ещё → «Установить на другие устройства»). Она сама определит, что у вас: Windows, Linux, Mac, Android, iPhone/iPad или телевизор.

## Вкладки

**📺 ТВ** — главный экран.
- Сверху выбор: 🇷🇺 Россия · 🇧🇾 Беларусь · Все · 🌍 Другие страны.
- «▶ Продолжить» — последние каналы.
- Категории: Общие, Новости, Спорт, Кино и сериалы, Детские, Музыка, Познавательные, Развлечения…
- «Только рабочие» — прятать каналы, которые не отвечают (рядом видно, сколько скрыто).
- Точка на карточке: 🟢 работает · 🟠 медленный · 🔴 не отвечает · серая — ещё не проверялся.
- Номер слева — для набора с пульта/клавиатуры. Номера идут сверху вниз.
- В режиме «Все» каналы разбиты на секции: «⭐ Главные каналы», Новости, Спорт, Кино и сериалы, Детские, Музыка, Познавательные, Развлечения, Общие, Региональные, Религия.
- «🔄 Проверить каналы» (в приложении) — проверить, какие каналы открываются в вашей сети. Делается и само раз в сутки.
- **Долгое нажатие на канал** — в избранное (или убрать).

**🔍 Поиск** — как на YouTube: вводите — появляются подсказки (каналы, ваши прошлые запросы, подсказки YouTube). Результаты: Всё · ТВ-каналы · Видео · Эфиры · Каналы YouTube · Фильмы. Можно латиницей (`ntv`, `pervyi`) и по номеру канала.

**▶️ Видео** (YouTube, можно выключить в Настройках) — сверху подборки официальных каналов: «🆕 Новинки кино — трейлеры и премьеры», «🧸 Новые мультфильмы», «🌸 Аниме», «🎞 Классика». С ключом YouTube API — ещё поиск, «В тренде» и рубрики (музыка, юмор, наука, спорт…). Видео играет в **официальном плеере YouTube**; на старых iPad (iOS 9–11) и Android 4.4 он не работает — там нужно своё зеркало (Настройки). Подробно — [YOUTUBE.md](YOUTUBE.md). Нажмите на канал автора → «Подписаться» — его видео будут в «Мои подписки» и в Избранном.

**▶️ Видео — поиск и фильтры** (нужен ключ YouTube API — бесплатно, 5 минут: Ещё → Настройки → «Ключ YouTube API» → «как получить»). Без ключа поиск откроет сайт YouTube. Фильтры: Видео / Прямые эфиры, длина (для фильмов и сериалов — «Больше 20 мин»), сортировка. В официальном плеере качество и субтитры выбираются кнопками самого YouTube; в режиме своего зеркала — кнопкой **⚙** (качество, озвучка, субтитры).

**🎬 Фильмы**
- Сверху — **🆕 новинки и трейлеры премьер**, новые мультфильмы и аниме с официальных каналов.
- Поиск фильма и фильтры: жанр (боевик, комедия, драма, ужасы, фантастика, аниме, триллер, фэнтези, семейные, исторические, биография, мюзикл, спорт, сериалы…), годы, советские/зарубежные. Результаты — из Архива кино и (с ключом YouTube API) полнометражные с YouTube.
- «🔎 Искать в Google» — откроет поиск в Safari.
- «📥 Загрузки» — скачанные фильмы (кнопка ⬇ в плеере у фильмов архива, своих mp4 и файлов с ПК); смотреть можно без интернета.
- «Продолжить просмотр» — с того места, где остановились.
- Классика — официальные каналы «Мосфильма» и «Беларусьфильма».
- Архив кино (общественное достояние): старые мультфильмы, мировая классика, фантастика, комедии, нуар, немое кино (бесплатно и легально).
- 🔗 Мои ссылки — вставьте ссылку на `.m3u8` или `.mp4`.
- 📁 Плейлисты M3U — свой список каналов; появится в «Другие страны → Мои плейлисты».
- 💻 Фильмы с компьютера — на ПК: `python tools/serve.py --media "D:\Фильмы"`, на iPad — адрес из окна сервера. iPad играет mp4/m4v/mov (H.264); mkv/avi — нет (конвертируйте в mp4).

**⭐ Избранное** — каналы (кнопка «Порядок и удаление»: ▲ ▼ ✕), видео, YouTube-каналы, фильмы.

**☰ Ещё**
- Дополнительно — Украина, Казахстан, Узбекистан и другие страны, подборки «Мир».
- Не работают — что не отвечает сейчас; можно попробовать, «Сбросить мои отметки».
- Настройки, Обновить список каналов, Помощь и сертификаты.

## Плеер

- Касание — показать/спрятать кнопки.
- Свайп ◀ ▶ — соседний канал, свайп вниз — закрыть.
- ☆ — в избранное · ☰ — список каналов сбоку · ⇄ — другой источник этого канала · ⛶ — весь экран.
- Фильмы: ползунок, −10 / +30 секунд, пауза. Позиция запоминается.
- **Программа передач (📋)** — у главных каналов России и Беларуси: в заголовке «Сейчас: … · Далее: …», кнопка 📋 — вся программа на сегодня-завтра. На карточках каналов под названием — что идёт сейчас.
- **Перемотка эфира** — если трансляция хранит последние минуты (не у всех каналов), появляются «−30» (назад) и красная «В эфир» (вернуться в прямой эфир). С пульта — ◀ ▶.
- **Следующая серия** — в конце видео или серии через 5 секунд включится следующее из списка («Смотреть сейчас» / «Отмена»). Выключается в Настройках.
- Если канал не ответил — плеер сам пробует резервные источники («источник 2 из 3»). Не помогло — кнопки «Ещё раз», «Следующий ▶», «Скрыть канал».

## Настройки

| Настройка | Что делает |
|---|---|
| Режим устройства | Авто / Лёгкий / Полный. Лёгкий — для старой техники: меньше анимаций и картинок, видео до 480p |
| Программа передач | показывать, что идёт сейчас и дальше |
| Следующее видео автоматически | в конце видео/серии — следующее через 5 с |
| Размер текста | Обычный / Крупный / Очень крупный — удобно издалека и для пожилых |
| PIN и Детский режим | родительский контроль: только детские каналы, мультфильмы, строгий поиск; выйти и открыть настройки — только по PIN |
| Перенести избранное | код или файл с избранным, подписками, ссылками и настройками — вставьте на другом устройстве (без регистрации) |
| Только рабочие каналы | прятать нерабочие |
| Резервные источники | при сбое сразу пробовать другой источник |
| Логотипы каналов | выключите на очень медленном интернете |
| Ждать источник | 8–20 с до перехода к резервному |
| Источник видео | Авто (по устройству) / Официальный плеер YouTube / Своё зеркало |
| Ключ YouTube API | ваш бесплатный ключ для поиска и подборок YouTube; хранится только на устройстве |
| Своё зеркало Invidious/Piped | для старых устройств, где официальный плеер не работает |
| Ваше устройство | что умеет устройство: система, лучшее качество, кодеки H.264/HEVC/VP9/AV1, HLS, WebM/MKV, официальный плеер YouTube |
| Адрес каталога | своя ссылка на catalog.json |

## Голосовой поиск

Кнопка 🎤 в строке поиска: Android и Android TV (системное распознавание речи, кнопка микрофона на пульте тоже подойдёт после нажатия 🎤), Chrome, Edge и Safari на ПК и телефонах. Говорите по-русски: «Первый канал», «мультфильмы», «новости».

## Частые вопросы

**Канал долго грузится / не идёт.** Подождите — плеер сам переключит источник. Не помогло — «Следующий ▶». Канал попадёт в «Не работают» и перестанет мешать. Раз в неделю-две — «Ещё → Обновить список каналов».

**На старом iPad почти ничего не открывается, YouTube пустой.** Установите сертификаты: Ещё → Помощь → «Установить сертификаты» (один раз).

**Видео YouTube не открывается / «YouTube не разрешил показ».** Автор запретил встраивание, есть возрастное ограничение или YouTube просит подтвердить, что вы не бот (часто при VPN). Выключите VPN или откройте видео на сайте YouTube кнопкой в плеере. Подробно — [YOUTUBE.md](YOUTUBE.md).

**Фильм не играет на этом устройстве.** Настройки → «Ваше устройство» покажет, какие форматы поддерживаются. Например, старый iPad не играет HEVC, MKV и видео выше 720p.

**Windows пишет «Система Windows защитила ваш компьютер».** Программа пока без цифровой подписи. «Подробнее» → «Выполнить в любом случае». Скачивайте только из Releases проекта ([SECURITY.md](../SECURITY.md)).

**Канал показывает «недоступно в вашей стране».** Это гео-блок правообладателя — переключитесь на соседний канал.

**Пропало избранное после переустановки.** Избранное хранится на устройстве; при обновлении поверх оно сохраняется, при удалении приложения — удаляется.
