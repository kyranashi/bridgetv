# Каталог каналов

## Откуда каналы

С версии 0.2.2 источников три (ссылки одного канала склеиваются по названию — `name_key()` / `merge_by_name()`):
- iptv-org: `countries/<код>.m3u` + `streams/<код>.m3u` (объединяются) и `languages/rus.m3u`;
- [Free-TV/IPTV](https://github.com/Free-TV/IPTV) — группы Russia и Belarus (значки Ⓢ Ⓖ Ⓨ убираются; YouTube, VK, OK.ru и DASH пропускаются);
- `data/sources_extra.json` — ручные официальные ссылки.

**Важно про проверку.** Доступность каналов зависит от страны. Если ПК выходит в интернет через VPN, проверка с ПК неточна — поэтому для РФ/РБ используется мягкий режим (`--soft ru,by`), а окончательная проверка делается на самом устройстве (`web/js/scan.js`, кнопка «Проверить каналы»).


Открытый каталог [iptv-org](https://github.com/iptv-org/iptv) — только публичные бесплатные трансляции:
- плейлисты по странам `https://iptv-org.github.io/iptv/countries/<код>.m3u` (запасной — `raw.githubusercontent.com/iptv-org/iptv/master/streams/<код>.m3u`);
- по категориям `…/iptv/categories/<категория>.m3u` — для подборок «Мир»;
- метаданные `https://iptv-org.github.io/api/channels.json` — кириллические названия (`alt_names`), категории, NSFW, закрытые каналы.

Отбрасываются: не-HLS ссылки (кроме mp4), NSFW/18+, закрытые каналы, магазины, платные пакеты России (`PAY` в `build_catalog.py`).

## Команды

```bash
python tools/build_catalog.py               # собрать + проверить (2–5 мин) → data/catalog.json, data/catalog.js
python tools/build_catalog.py --no-check    # только собрать
python tools/build_catalog.py --recheck     # перепроверить текущий каталог
python tools/build_catalog.py --only ru,by  # только эти регионы (world — подборки «Мир»)
python tools/build_catalog.py --soft ru,by  # мягкая проверка (из-за границы, для CI)
python tools/check_streams.py URL [URL…]    # проверить отдельные ссылки
```

**Проверяйте из своей страны.** Многие каналы РФ/РБ отдают видео только внутри страны. Запуск с ПК в России/Беларуси даёт точный результат; закоммитьте его — приложения скачают.

## Как проверяется ссылка (`check_streams.py`)

1. `GET` master-плейлиста с User-Agent плеера iOS 9 (`AppleCoreMedia/1.0.0.13G36 (iPad; …)`), таймаут 8 с.
2. Master → разбор вариантов (`BANDWIDTH`, `RESOLUTION`, `CODECS`); выбирается самый лёгкий **не-HEVC** (старые устройства HEVC не декодируют). Если есть только HEVC/AV1/VP9 — «только HEVC».
3. `GET` media-плейлиста; `SAMPLE-AES`/FairPlay → «DRM» (не сыграет).
4. `GET` первых 2 КБ первого сегмента (Range) — сервер реально отдаёт видео.
5. Время до первого байта > 4 с → «медленный».

Статусы варианта `s`: `1` рабочий, `2` медленный, `3` гео-блок/запрет (401/403/451), `-1` не работает, `0` не проверялся. Поле `e` — причина: `таймаут`, `нет связи`, `нет домена`, `HTTP 404`, `TLS`, `обрыв`, `не плейлист`, `только HEVC`, `DRM`…

Канал: `ok: 1`, если хоть один вариант 1/2. Варианты сортируются: рабочие и быстрые — первыми.

Мягкий режим (`--soft ru,by`): канал этих регионов прячется, только если **все** его ссылки «точно мертвы» (`нет домена`, `HTTP 404/410`, `не плейлист`, `только HEVC`, `DRM`).

## Формат `data/catalog.json` (format 2)

```jsonc
{
  "app": "BridgeTV", "format": 2, "version": "2026-11-09", "checked": "2026-11-09 14:45",
  "source": "iptv-org …",
  "regions": [
    {"id": "ru", "name": "Россия", "flag": "🇷🇺", "primary": true},
    {"id": "ua", "name": "Украина", "flag": "🇺🇦", "primary": false},
    {"id": "w-news", "name": "Мир: Новости", "flag": "🌐", "primary": false, "world": true}
  ],
  "categories": [{"id": "general", "name": "Общие"}, {"id": "news", "name": "Новости"}],
  "channels": [
    {
      "id": "NTV.ru",            // id iptv-org (или нормализованное имя)
      "n": "НТВ",                // название (кириллица, если есть)
      "r": "ru",                 // регион
      "c": "general",            // категория
      "l": "https://…/logo.png", // логотип
      "num": 3,                  // номер в регионе
      "ok": 1,                   // канал рабочий по проверке
      "v": [                     // варианты (резервные источники), лучшие — первыми
        {"u": "https://…/index.m3u8", "q": "720p", "s": 1, "ms": 1093, "hi": 720, "lo": 360},
        {"u": "http://…/playlist.m3u8", "s": -1, "e": "таймаут", "geo": 1, "part": 1,
         "h": {"ua": "…", "ref": "…"}}   // geo — iptv-org помечает гео-блок; part — не 24/7; h — нужные заголовки
      ]
    }
  ]
}
```
`data/catalog.js` — то же самое в виде `window.TV_CATALOG = {…};` (подключается тегом `<script>`, работает с `file://` и в старых браузерах).

## Сортировка, секции и иконки (с 0.2.3)

- `reorganize()`: «Главные каналы» (`"top": 1`) → категории в порядке `CATEGORIES` → алфавит (кириллица, латиница, цифры). Местные каналы (`api/feeds.json`, зона вещания — область/город) → категория `region`. Номера `num` — сверху вниз.
- Поле `"li": "logos/<хэш>.png"` — встроенная иконка (делает `tools/build_logos.py`, после `build_catalog.py`).
- Поле `"built"` — дата и время сборки: приложение выбирает более свежий каталог (встроенный или скачанный).
- `python tools/build_catalog.py --reorg` — пересортировать без сети и проверки.

## Категории

`general` Общие · `news` Новости · `sport` Спорт · `movies` Кино и сериалы · `kids` Детские · `music` Музыка · `docs` Познавательные · `fun` Развлечения · `region` Региональные · `religion` Религия. Соответствие категориям iptv-org — `CAT_MAP` в `build_catalog.py`.

## Порядок «как на пульте»

`RU_TOP` (первый и второй мультиплексы: Первый, Россия‑1, Матч ТВ, НТВ, Пятый, Россия‑К, Россия‑24, Карусель, ОТР, ТВ Центр, РЕН ТВ, Спас, СТС, Домашний, ТВ‑3, Пятница, Звезда, Мир, ТНТ, Муз‑ТВ) и `BY_TOP` (Беларусь 1–3, ОНТ, СТВ, НТВ‑Беларусь, РТР‑Беларусь, Мир, Беларусь 5, Беларусь 24…). Сопоставление — по нормализованному id iptv-org. Номера — подряд (канала нет в каталоге — номер не пропускается).

## Ручные источники — `data/sources_extra.json`

Если у важного канала нет рабочей ссылки, а у вас есть **официальная открытая** трансляция:
```json
{
  "channels": [
    {"id": "Perviykanal.ru", "v": ["https://…/официальная.m3u8"]},
    {"id": "my-local-tv", "n": "Местный канал", "r": "by", "c": "general", "v": ["https://…/index.m3u8"]}
  ]
}
```
Существующему каналу ссылки добавляются первыми вариантами; несуществующий канал создаётся. Затем `python tools/build_catalog.py`.

## Автообновление

`.github/workflows/catalog.yml` — каждый понедельник собирает каталог с `--soft ru,by` и коммитит, если он изменился. Приложения получают его кнопкой «Ещё → Обновить список каналов» (источники: своя ссылка → сервер, с которого открыто → `cdn.jsdelivr.net/gh/<REPO>@main/data/catalog.json` → `raw.githubusercontent.com/…`). Для этого после публикации впишите репозиторий в `web/js/core.js` → `TV.REPO = 'владелец/репозиторий'`.
