# Политика конфиденциальности BridgeTV

Редакция от 11.11.2026, версия приложения 0.3.0.

## Кратко

BridgeTV **не собирает, не хранит у себя и не передаёт** персональные данные. У проекта нет своего сервера, аккаунтов, рекламы, аналитики и трекеров.

## Что хранится на вашем устройстве

Избранное, история просмотра, настройки, результаты проверки каналов, загруженные фильмы и (если вы его ввели) ключ YouTube API. Эти данные не покидают устройство. Удалить их можно, удалив приложение (в браузере — очистив данные сайта).

## К каким сервисам обращается устройство

Как и обычный браузер, приложение напрямую соединяется с источниками, которые вы смотрите. Они видят ваш IP-адрес и тип устройства и обрабатывают их по своим правилам:

| Сервис | Когда | Правила |
|---|---|---|
| Серверы телеканалов (из каталогов iptv-org, Free-TV) | при просмотре и проверке каналов | правила владельца сервера |
| YouTube (встроенный плеер `youtube-nocookie.com`, RSS-ленты, YouTube Data API) | только когда вы открываете вкладку «Видео»/«Фильмы» или запускаете ролик | [Условия YouTube](https://www.youtube.com/t/terms), [Политика конфиденциальности Google](https://policies.google.com/privacy) |
| GitHub, jsDelivr | обновление каталога каналов и страница плеера YouTube | [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) |
| archive.org | фильмы «Архива кино» | правила Internet Archive |
| wsrv.nl | только в лёгком режиме — уменьшение логотипов каналов | правила wsrv.nl |
| Ваше зеркало Invidious/Piped | только если вы указали его в Настройках | правила вашего сервера |

Встроенный плеер YouTube загружается **только когда вы сами запускаете видео**. Используется домен youtube-nocookie.com (режим повышенной конфиденциальности), но YouTube всё равно может сохранять данные в браузере плеера.

## Ключ YouTube API

Ключ — ваш собственный. Он хранится только на устройстве и отправляется только на `www.googleapis.com`. Использование API регулируется [Условиями API-сервисов YouTube](https://developers.google.com/youtube/terms/api-services-terms-of-service).

## Дети

Приложение не предназначено для сбора данных детей и не собирает их. Безопасный поиск YouTube (`safeSearch=moderate`) включён.
