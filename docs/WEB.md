# Веб-версия: iPad, Android, Smart TV, компьютер

Веб-версия — тот же интерфейс, что и в iOS-приложении. Работает в любом браузере, начиная с Safari iOS 9 и Android 4.4.

## Запуск с компьютера по Wi‑Fi (рекомендуется)

```bash
python tools/serve.py                       # только приложение
python tools/serve.py --media "D:\Фильмы"   # + ваши фильмы для вкладки «Фильмы с ПК»
```
Сервер напечатает адреса вида `http://192.168.1.10:8080/web/`. Откройте его на устройстве в той же сети.

- **Windows:** при первом запуске разрешите Python доступ в «Частные сети» (окно брандмауэра). Если окна не было — Панель управления → Брандмауэр → Разрешить приложение → Python.
- **iPad/iPhone:** Safari → «Поделиться» → **«На экран Домой»** — приложение откроется на весь экран со своей иконкой.
- **Android:** Chrome → ⋮ → «Добавить на главный экран».
- **Smart TV:** встроенный браузер → адрес → в закладки. Управление пультом (см. ниже).

Почему локальный сервер лучше, чем открыть файл: работают обновление каталога, «Фильмы с ПК», перемотка (Range), http-трансляции (на https-странице они блокируются браузером).

## GitHub Pages

После публикации репозитория: Settings → Pages → Source: **GitHub Actions**. Workflow `pages.yml` выложит сайт на `https://<владелец>.github.io/<репо>/web/`.

Ограничение: страница по https **не может** играть `http://`-трансляции (mixed content). Плеер сам пробует `https://`-вариант того же адреса, но часть каналов будет недоступна. Для полного списка — приложение или локальный сервер.

## Совместимость

| Браузер | HLS | Примечание |
|---|---|---|
| Safari iOS 9–17, macOS | встроенный | на iOS 9–10 нужен профиль сертификатов (Ещё → Помощь) |
| Chrome / Edge / Firefox (ПК) | hls.js (или встроенный в новых Chrome) | нужны CORS-заголовки у трансляции — без них канал уйдёт на резервный источник |
| Android 5+ Chrome / WebView | hls.js (MSE) | |
| Android 4.4 | hls.js, если есть MSE | лёгкий режим |
| Tizen / webOS / Android TV | встроенный или hls.js | клавиши «Назад» 10009 / 461 поддержаны |

## Управление с пульта и клавиатуры

| Где | Клавиша | Действие |
|---|---|---|
| Везде | ← ↑ → ↓ | перемещение по экрану |
| | OK / Enter | выбрать |
| | Назад / Esc / Backspace | назад |
| Главный экран ТВ | цифры | открыть канал по номеру |
| Плеер (каналы) | ↑ ↓, CH+/CH−, PageUp/PageDown | следующий / предыдущий канал |
| | ← → | предыдущий / следующий канал |
| | цифры | набор номера канала |
| | OK | показать / скрыть панель |
| Плеер (фильмы) | ← → | −10 с / +30 с |
| | Пробел, ▶❚❚ | пауза |

## Лёгкий режим

Включается автоматически (Настройки → Режим устройства → Авто) на iOS < 12, Android < 7, устройствах с ≤ 1 ГБ памяти или ≤ 2 ядрами. Что меняется: нет анимаций и теней, логотипы уменьшаются через `wsrv.nl` до 96 px, превью YouTube 120×90, списки по 48 карточек, полки грузятся по одной, hls.js ≤ 480p с минимальным стартовым качеством и коротким буфером, +4 с к ожиданию источника.

## Работа без интернета

Интерфейс и список каналов работают из файлов (сервер или приложение). Нужен интернет только для самих трансляций, YouTube и архива.
