# Общий поиск YouTube без ключа (1.4.0) — заготовка

Сейчас без своего ключа во вкладке «Видео» работают подборки официальных каналов и «Популярное за 3 дня»,
а поиск открывает сайт YouTube. Чтобы искать прямо в приложении **всем** пользователям без ключа,
нужен маленький сервер: он ходит в официальный YouTube Data API v3 со своим ключом владельца приложения.
Код готов — `server/yt-proxy/` (Cloudflare Worker). Включается, только когда владелец сделает шаги ниже.

## Что делает сервер
- Пропускает только `search` и `videos` и только известные параметры; ключ добавляет сам (секрет `YT_KEY`).
- Кэширует ответы на 6 часов — одинаковые поиски не тратят квоту.
- Отвечает CORS только сайту приложения; чужие сайты получают 403. Тексты ошибок Google наружу не отдаёт.

## Стоимость и пределы
- Cloudflare Workers — бесплатный план (100 000 запросов в сутки).
- YouTube Data API — бесплатно, квота 10 000 единиц в сутки; поиск стоит 100 → **около 100 новых поисков в сутки
  на всех** (повторы из кэша бесплатны). Когда квота кончается, Google отвечает 403, приложение пишет
  «исчерпан на сегодня», денег это не стоит. Больше квоты — заявка в Google (бесплатно, с проверкой).

## Шаги (делает владелец, ключи в чат и в git не вставлять)
1. Google Cloud Console → новый проект → «YouTube Data API v3» → Enable → Credentials → API key.
   Ограничить ключ: API restrictions → только YouTube Data API v3.
2. Аккаунт Cloudflare (бесплатный). В папке `server/yt-proxy`:
   ```bash
   npx wrangler login
   ```
   ```bash
   npx wrangler secret put YT_KEY
   ```
   ```bash
   npx wrangler deploy
   ```
   Wrangler покажет адрес вида `https://bridgetv-yt.<имя>.workers.dev`.
3. В `web/js/core.js` вписать адрес **со слешем в конце**: `TV.YT_PROXY = 'https://bridgetv-yt.<имя>.workers.dev/';`
4. До выпуска — дописать в `docs/PRIVACY.md` (РБ: ОЗПД; ЕС: GDPR) абзац ниже.

## Абзац для Политики конфиденциальности
> Поиск видео YouTube в приложении без вашего ключа идёт через наш сервер на Cloudflare (Cloudflare, Inc., США):
> он передаёт текст запроса в YouTube Data API (Google LLC) и хранит ответы в кэше до 6 часов. Мы не храним
> журналы запросов и не связываем их с вами; Cloudflare и Google обрабатывают IP-адрес по своим политикам.
> Если вы указали свой ключ YouTube в Настройках, запросы идут напрямую в Google, минуя наш сервер.

## Отключить
Очистить `TV.YT_PROXY` (пустая строка) и выпустить обновление; сервер удалить командой `npx wrangler delete`.
