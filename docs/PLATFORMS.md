# Платформы и совместимость

## Для чего создавалось (реферат)

**Исходное устройство:** iPad mini 1-го поколения, модель A1455 (MD543, белый, 16 ГБ), процессор Apple A5 (2 ядра, 1 ГГц), 512 МБ ОЗУ, архитектура armv7, iOS 9.3.6 (последняя для этой модели), джейлбрейк.

**Проблема.** В 2026 году такой планшет почти бесполезен: App Store не даёт ставить актуальные приложения, YouTube и большинство сайтов не открываются (устаревшие браузер и корневые сертификаты), а готовые IPTV-плееры требуют iOS 12+.

**Задача.** Сделать телевизор, который:
1. работает только от Wi‑Fi, без компьютера;
2. показывает каналы России и Беларуси, а остальные страны — в разделе «Дополнительно»;
3. ищет и показывает видео, прямые эфиры и фильмы;
4. не тормозит на 512 МБ памяти и сам обходит мёртвые ссылки;
5. работает на любой другой технике — от старого Android и Smart TV до ПК.

**Решения, которые дали совместимость:**

| Ограничение старого iPad | Решение | Почему помогает и на другой технике |
|---|---|---|
| Safari iOS 9: нет современного JavaScript и CSS | интерфейс на ES5, flexbox без grid/gap, без фреймворков | работает в любом браузере за последние ~10 лет, в том числе в браузерах телевизоров |
| A5 декодирует только H.264 до 720p | проверка каталога отбрасывает HEVC-only потоки; лёгкий режим ≤ 480p | слабые Android и ТВ тоже получают лёгкие потоки |
| 512 МБ ОЗУ | списки порциями, уменьшенные логотипы, без анимаций | экономит память на любых слабых устройствах |
| нет корней Let's Encrypt / Sectigo 2021+ | свои корни в запросах приложения + профиль для системы | то же нужно iOS 10, старым Android (< 7.1) и ТВ |
| ссылки умирают | проверка «глазами iPad», резервные источники, обновление каталога через GitHub | одинаково для всех платформ |
| нет пульта, но есть ТВ | пространственная навигация, клавиши пульта | работает на Smart TV и ПК |

## Где поддерживается (с 0.3.0)

| Устройство | Формат | Статус | Примечания |
|---|---|---|---|
| iPad mini 1 / iPad 2–4 / iPhone 4S–5 (iOS 9–10) | `.ipa` (джейлбрейк или Sideloadly) или Safari → «На экран Домой» | ✅ основная цель | лёгкий режим; профиль сертификатов обязателен; HEVC нет |
| iPhone / iPad на iOS 11–18 | `.ipa` (Sideloadly, AltStore, TrollStore) или Safari → «На экран Домой» | ✅ | arm64, на весь экран (экраны запуска, `UILaunchScreen`) |
| Android 4.4–6 | `.apk` или браузер | ✅ | TLS 1.2 и корни Let's Encrypt в приложении; лёгкий режим |
| Android 7–15, Android TV, приставки | `.apk` | ✅ | пульт, иконка в меню Android TV |
| Samsung Smart TV (Tizen 2.3+) | `.wgt` (подпись в Tizen Studio) или браузер ТВ | ✅ | пульт: стрелки, OK, Назад, цифры, CH±, медиакнопки |
| LG Smart TV (webOS 3+) | `.ipk` (Developer Mode) или браузер ТВ | ⚠️ экспериментально | |
| Windows 10/11, Linux | программа `BridgeTV-windows-setup.exe` / `-portable.exe` / `BridgeTV-linux.AppImage` | ✅ с 0.3.0 | Electron; все каналы, подборки YouTube без ключа — [DESKTOP.md](DESKTOP.md) |
| Windows / macOS / Linux / ChromeOS | веб-приложение (PWA: «Установить» в браузере) или `web.zip` | ✅ | клавиатура как пульт; `web.zip` раздаёт приложение по Wi‑Fi |
| Старые ТВ (Opera TV, NetCast) | браузер | ⚠️ частично | без MSE и без встроенного HLS видео не пойдёт |

Все форматы — один и тот же интерфейс `web/`; различается только оболочка: `ios/` (WKWebView), `android/` (WebView), `desktop/` (Electron), PWA (`web/manifest.json`, `web/sw.js`), пакеты ТВ (`tools/package.py`). Сайт https://kyranashi.github.io/bridgetv/ (корневой `index.html`) сам определяет устройство и предлагает нужный файл.

С 0.3.0 приложение ещё и **подстраивается под устройство**: `TV.caps` (`web/js/core.js`) проверяет, какие кодеки и форматы видео поддерживаются (H.264, HEVC, VP9, AV1, HLS, WebM/MKV) и какое качество тянет экран; по этому выбирается источник видео YouTube ([YOUTUBE.md](YOUTUBE.md)), лёгкий режим и фильмы с ПК. Список возможностей — Настройки → «Ваше устройство».

## Как добавляется новая платформа

Интерфейс общий (`web/`). Для нативной оболочки нужно:
1. Показать `web/index.html` из ресурсов в WebView.
2. Внедрить `window.TV_NATIVE = {platform, app, os}` до загрузки страницы.
3. Реализовать сообщения моста (`fetch`, `awake`, `open`, `certs` — по необходимости) и вызывать `TV.nativeCb(id, err, text, status)`.

iOS — `ios/src/main.m` (`window.webkit.messageHandlers.tv`); Android — `Bridge.java` (`window.TVAndroid`); ПК — `desktop/preload.js` (`window.TVBridge`). В `core.js` синхронные мосты Android и ПК обрабатываются одинаково (`TV._bridge`).
