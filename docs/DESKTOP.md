# BridgeTV на ПК и «одно приложение везде» (с 0.3.0)

Один и тот же интерфейс `web/` работает везде; различается только «оболочка». С 0.3.0 есть три способа поставить BridgeTV на компьютер — пользователь выбирает на странице **https://kyranashi.github.io/bridgetv/web/install.html**, она сама определяет устройство.

| Способ | Платформы | Плюсы | Минусы |
|---|---|---|---|
| **Программа BridgeTV** (`BridgeTV-windows-setup.exe`, `BridgeTV-windows-portable.exe`, `BridgeTV-linux.AppImage`) | Windows 10/11, Linux | все каналы (в т.ч. http и без CORS), подборки YouTube без ключа, загрузки, не гасит экран | ~80–95 МБ; пока без цифровой подписи (SmartScreen) |
| **Веб-приложение (PWA)** — «Установить» в Chrome/Edge, «Добавить в Dock» в Safari | Windows, macOS, Linux, ChromeOS, Android | без скачивания файлов, обновляется само, работает без интернета (интерфейс) | на https-сайте часть http-каналов недоступна; подборки YouTube только с ключом |
| **web.zip + локальный сервер** | любой ПК с Python | раздаёт приложение на iPad/ТВ по Wi‑Fi, фильмы с ПК | нужен Python |

## Программа (Electron)

Папка `desktop/`:

| Файл | Что делает |
|---|---|
| `main.js` | окно, своя схема `bridgetv://app/` (файлы `web/`, `data/`, загрузки), мост команд, защита |
| `preload.js` | единственная связь страницы с системой: `window.TVBridge` (`info`, `saved`, `postMessage`) — тот же набор, что у Android |
| `package.json` | версии Electron/electron-builder, настройки сборки и **Electron Fuses** |
| `build/icon.ico`, `icon.png` | иконка (делает `tools/make_icons.py`) |

Сборка — GitHub Actions `.github/workflows/desktop.yml` (Windows и Linux), при теге `v*` файлы попадают в релиз. Локально (нужен Node.js 20+):

```bash
cd desktop
npm install
npm start          # запуск из исходников
npm run dist       # установщик в ../dist
```

### Защита программы
- страница работает в песочнице: `contextIsolation`, `sandbox`, без Node.js, `webSecurity` включена;
- файлы отдаются только из папок `web/`, `data/` и загрузок, без выхода выше (`inside()`), с заголовком CSP;
- переходы на чужие сайты и новые окна запрещены, ссылки уходят в браузер (только http/https);
- разрешения сайтов (камера, микрофон, геолокация, уведомления) отклоняются;
- команды моста — по списку, с проверкой типов и размеров (ответы fetch ≤ 32 МБ, записи ≤ 8 МБ);
- Electron Fuses: нельзя запустить программу как Node.js, нельзя подменить код вне подписанного архива asar, отключены `NODE_OPTIONS` и `--inspect`;
- заголовки CORS ослабляются **только для запросов самой страницы приложения** (не для встроенного плеера YouTube и других фреймов) — чтобы открывались IPTV-потоки без CORS.

## PWA

- `web/manifest.json` — название, иконки 192/512 и «маскируемая» для Android, `display: standalone`.
- `web/sw.js` — service worker: интерфейс из кэша (обновляется в фоне), каталог — сначала из сети. Видео, API и картинки не кэшируются. Имя кэша меняется с версией (`tools/bump_version.py`).
- Регистрируется только на https-сайте и не в приложениях (`web/index.html`). Старые браузеры (iOS 9–11) просто работают как сайт.

## macOS

Отдельной программы нет (без подписи Apple её неудобно ставить). Рекомендуется PWA: Safari → «Файл» → «Добавить в Dock» (macOS 14+) или установка из Chrome/Edge.
