# Схема версий BridgeTV

С 10.11.2026 версии нумеруются так: **`ОСНОВНОЙ.ГЛОБАЛЬНОЕ.ПРАВКИ`**, например **0.2.5**.

| Цифра | Что значит | Когда увеличивать | Пример |
|---|---|---|---|
| **1-я — основной релиз** | `0` — проект в разработке; `1` — первый полноценный, проверенный на всех платформах релиз; дальше — новые поколения приложения | только при выпуске полноценного релиза | 0.9.3 → **1.0.0** |
| **2-я — глобальное обновление** | крупные изменения: новые вкладки, платформы, переделка интерфейса или архитектуры | при каждом крупном обновлении; **3-я цифра обнуляется** | 0.2.5 → **0.3.0** |
| **3-я — мелкие правки** | исправления ошибок, небольшие улучшения, обновление текстов и каталога | при каждом выпуске с правками | 0.2.5 → **0.2.6** |

**11.11.2026 выпущен 1.0.0** — первый полноценный релиз. Дальше: правки — 1.0.x, крупные обновления — 1.x.0.

**Тег на GitHub** — `v` + версия: `v1.0.0`. Тег запускает сборку всех файлов релиза (IPA, APK, web.zip, .wgt, .ipk).

## Алгоритм выпуска (каждый раз)
1. Сделать изменения, проверить (браузер + по возможности устройство).
2. Поднять версию одной командой — она меняет все нужные файлы:
   ```bash
   python tools/bump_version.py patch    # мелкие правки:        0.2.5 -> 0.2.6
   python tools/bump_version.py minor    # глобальное обновление: 0.2.5 -> 0.3.0
   python tools/bump_version.py major    # полноценный релиз:     0.9.x -> 1.0.0
   ```
   Меняются: `web/js/core.js` (TV.VERSION), `ios/src/main.m` (kAppVersion), `ios/res/Info.plist` (версия + номер сборки CFBundleVersion +1), `android/app/build.gradle` (versionName + versionCode +1), строка «Версия» в README.
3. Дописать раздел в `CHANGELOG.md` и шаг в `docs/devlog/`.
4. Коммит, `git push`, затем `git tag v0.2.6` и `git push origin v0.2.6` → GitHub соберёт и приложит файлы к релизу.

## Номера сборок
- **iOS `CFBundleVersion`** и **Android `versionCode`** — служебные номера, **только растут** (на 1 с каждым выпуском), иначе iOS/Android не поставят обновление поверх. Они не зависят от схемы выше (versionCode был 250 у старой 2.5.0, поэтому 0.2.5 = 251).
