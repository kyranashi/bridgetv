# 📺 BridgeTV

**Мост между старой техникой и современным ТВ: телеканалы, видео и фильмы для любого устройства — от iPad mini 1 на iOS 9 до Smart TV и ПК.**
Открытый код, без рекламы, без регистрации. Только бесплатные открытые источники.

> Название — `TV.APP_NAME` в `web/js/core.js`, `<title>` в `web/index.html`, `CFBundleDisplayName` в `ios/res/Info.plist`. В коде глобальный объект по-прежнему называется `TV`.

## О проекте

Приложение создавалось для одного конкретного устройства — **iPad mini 1-го поколения** (A1455, процессор Apple A5, 512 МБ памяти, armv7, iOS 9.3.6). Это планшет 2012 года: Apple давно его не обновляет, App Store для него почти пуст, YouTube и большинство сайтов на нём не открываются. Цель — вернуть старой технике пользу: сделать из неё телевизор с каналами России и Беларуси, видео и фильмами, который работает **только от Wi‑Fi, без компьютера**.

Из-за таких ограничений приложение получилось «всеядным»:
- интерфейс написан на самом старом JavaScript (ES5) и без тяжёлых библиотек — поэтому он работает и в Safari iOS 9, и в любом новом браузере;
- видео идёт в форматах, которые понимает любое устройство (HLS и mp4 с H.264), а там, где браузер сам не умеет HLS, подключается hls.js;
- «лёгкий режим» включается сам на слабых устройствах, а управление с пульта — на телевизорах;
- проблема старых сертификатов (из-за неё на старой технике «ничего не грузится») решена внутри приложения.

| Уровень | Устройства | Как |
|---|---|---|
| 🎯 Целевое | iPad mini 1, iPad 2/3/4, iPhone 4S/5 на iOS 9–10 | приложение `BridgeTV.ipa` (джейлбрейк) или Safari |
| ✅ Поддерживается | iPad/iPhone на iOS 11+, Android 5+, Android TV, Samsung Tizen, LG webOS, Windows/macOS/Linux | приложение, программа для ПК, PWA или браузер |
| ⚠️ По возможности | Android 4.4, старые Smart TV (2014–2016) | браузер, лёгкий режим |

Подробно — [docs/PLATFORMS.md](docs/PLATFORMS.md).

## Что умеет

- **ТВ** — Россия и Беларусь на главном экране, порядок как в эфирном пакете (Первый, Россия‑1, НТВ, Пятый…) и номера каналов для набора с пульта, категории (Новости, Спорт, Кино, Детские…), «Продолжить», статус каждого канала (🟢 работает · 🟠 медленный · 🔴 не отвечает).
- **Нерабочие каналы не мешают** — каталог проверяется «глазами iPad», нерабочие прячутся в «Ещё → Не работают». В плеере источники перебираются автоматически, а приложение запоминает, какие работают именно у вас.
- **Поиск как на YouTube** — подсказки при вводе, история, результаты сразу по телеканалам, видео, прямым эфирам, каналам YouTube и фильмам. Понимает латиницу («pervyi» → «Первый») и категории («новости» → все новостные каналы).
- **Видео** — подборки официальных каналов (новинки кино и трейлеры, мультфильмы, аниме), поиск, тренды и рубрики YouTube. **Официальный плеер YouTube** на новых устройствах, своё зеркало — на старых; приложение выбирает само по возможностям устройства. Поиск — с вашим бесплатным ключом YouTube API ([docs/YOUTUBE.md](docs/YOUTUBE.md)). Не связано с YouTube/Google.
- **Фильмы** — **🆕 новинки и трейлеры премьер**, новые мультфильмы и аниме с официальных каналов; поиск с фильтрами по **жанру** (в т.ч. аниме, триллер, фэнтези, семейные, сериалы…), **годам и стране** по YouTube и Архиву кино; «Искать в Google»; классика «Мосфильма» и «Беларусьфильма»; **загрузки на iPad** для просмотра без интернета (Архив кино, свои mp4, файлы с ПК); фильмы с компьютера по Wi‑Fi; «продолжить с места остановки».
- **Программа передач** — что идёт сейчас и дальше на главных каналах России и Беларуси, программа на сегодня-завтра (📋 в плеере).
- **Перемотка эфира** («−30», «В эфир») там, где трансляция это позволяет; **следующая серия** включается сама.
- **Родительский контроль** — детский режим с PIN; **крупный текст**; **перенос избранного** на другое устройство кодом или файлом; **голосовой поиск** (Android TV, Android, Chrome/Edge/Safari).
- **Безопасный режим** — скрывает источники, признанные нежелательными в РФ или экстремистскими в РБ (включён по умолчанию).
- **Избранное** — каналы (с сортировкой), видео, YouTube‑каналы, фильмы.
- **Дополнительно** — Украина, Казахстан, Узбекистан, Кыргызстан, Таджикистан, Грузия, Армения, Азербайджан, Молдова, Латвия, Литва, Эстония, Польша, Израиль, Германия, Турция + подборки «Мир» (новости, спорт, детские, музыка, кино, познавательные).
- **Под старую технику** — «лёгкий режим» включается сам: без анимаций, меньше картинок, качество до 480p, экономия памяти. Управление с пульта (стрелки, OK, цифры, CH±).

## Быстрый старт

### iPad / iPhone — приложение (лучший вариант для iOS 9)
1. Скачайте `BridgeTV.ipa` (GitHub → Releases или артефакт сборки «Сборка iOS»).
2. Джейлбрейк + AppSync Unified → 3uTools → «Приложения» → «Импорт» → `BridgeTV.ipa`.
3. Первый запуск на iOS 9–10: **Ещё → Помощь → «Установить сертификаты»** (один раз). Подробно — [docs/IOS.md](docs/IOS.md).

### iPad, Android, телевизор — без установки, через ПК по Wi‑Fi
```bash
python tools/serve.py --media "D:\Фильмы"
```
Откройте на устройстве адрес, который покажет сервер (`http://192.168.x.x:8080/web/`). На iPad: Safari → «Поделиться» → «На экран Домой». Подробно — [docs/WEB.md](docs/WEB.md).

### Компьютер
То же самое, `http://localhost:8080/web/`, или веб-версия онлайн: **https://kyranashi.github.io/bridgetv/web/** (на https часть http-каналов недоступна — см. [docs/WEB.md](docs/WEB.md)).

## Участие

Pull request'ы приветствуются. Перед отправкой:
- веб-код — только ES5 (см. «Правила кода» в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)), проверка на старом устройстве или в «лёгком режиме»;
- iOS — правила из [docs/IOS.md](docs/IOS.md) (без `@[]`, `@try`, API новее iOS 9);
- новые источники каналов — только официальные открытые трансляции (`data/sources_extra.json`).

## Правовое

Приложение не хранит и не распространяет видео. Каналы — ссылки на бесплатные трансляции из открытых каталогов [iptv-org](https://github.com/iptv-org/iptv) и [Free-TV](https://github.com/Free-TV/IPTV); иконки каналов — только для узнавания; видео YouTube — через официальный плеер и API YouTube (проект не связан с YouTube и Google); фильмы — официальные каналы киностудий и коллекции общественного достояния [archive.org](https://archive.org). Если вы правообладатель и ссылка нарушает ваши права — создайте issue, она будет удалена. Подробный разбор — [docs/LEGAL.md](docs/LEGAL.md).
