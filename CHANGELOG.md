# История версий

Номера версий — по схеме **0.ГЛОБАЛЬНОЕ.ПРАВКИ** ([docs/VERSIONING.md](docs/VERSIONING.md)). До 10.11.2026 использовалась старая нумерация (1.0, 2.0.0 … 2.5.0) — она указана в скобках.

## 1.2.0 — 12.11.2026 — сайт для скачивания, русские описания фильмов
- **Сайт https://kyranashi.github.io/bridgetv/** — одна ссылка: сайт сам определяет устройство и даёт кнопку «Скачать»; все платформы, веб-версия, проверка подлинности файлов. Старая страница установки перенаправляет туда.
- **Фильмы:** окна «🎭 Жанр» (только жанры) и «📅 Год» (только годы) разделены, выбор сразу возвращает к каталогу; дублирующий ряд жанров убран; **русские описания** (≈480 фильмов, из Википедии с указанием источника) и «Перевести на русский» для остальных; строгое совпадение по году.
- **Смотреть бесплатно:** во «Фильмах» раздел «▶ Можно смотреть бесплатно» сразу под «Новинками» — полные фильмы с официальных каналов киностудий (Мосфильм, Беларусьфильм) и из архива общественного достояния. На странице старого фильма — «▶ Смотреть фильм бесплатно», если он в общественном достоянии (только записи с явной пометкой public domain — чужие загрузки охраняемых фильмов не показываются).
- **Безопасность:** исправлены оба предупреждения сканера кода (CodeQL); проверка по чек-листу «27 проверок перед запуском»; действия сборки обновлены (checkout 7, cache 6, upload-pages-artifact 5, CodeQL 4 — закреплены по хэшам); проверка каждого коммита на утёкшие ключи (gitleaks); точные версии библиотек программы для ПК (`package-lock.json`, `npm ci`). Обновление Android Gradle Plugin 9 отклонено — оно убрало бы поддержку Android 4.4.
- **Свой адрес сайта:** подготовлено подключение домена одной настройкой (`docs/SITE.md`); bridgetv.org занят — свободные варианты в документе.
- Исправлена команда для ключа подписи Android в `docs/ANDROID.md`.
- Журнал: `docs/devlog/13-site-ru-descriptions-security27.md`.

## 1.1.0 — 11.11.2026 — вкладки «Видео» и «Фильмы» разделены
- **Фильмы — каталог как в онлайн-кинотеатре:** постеры, жанры (боевики, комедии, ужасы, фантастика, аниме, семейные…), годы, поиск по названию и режиссёру, **новые первыми**. Страница фильма: описание, длительность, рейтинг, режиссёр, **официальный трейлер**, «Где смотреть» (Кинопоиск, Apple TV, Иви), похожие. Около 1300 фильмов, обновляется каждый день (`tools/build_movies.py`: каталог Apple + русские названия из Wikidata).
- **Выбор жанра и года — отдельным окном** (кнопки «🎭 Жанр ▾» и «📅 Год ▾», все варианты сразу со счётчиками, «Показать N фильмов», «Сбросить»). Ряды жанров и полки на ПК листаются колесом мыши, перетаскиванием и стрелками ‹ ›.
- **Фильмы не перемешиваются с видео:** во «Фильмах» нет роликов YouTube; «Бесплатно» — только фильмы в общественном достоянии.
- **Видео — YouTube:** «🔥 В тренде» первым (с ключом API), свежие рубрики; трейлеры и фильмы оттуда убраны.
- Журнал: `docs/devlog/12-movies-catalog.md`.

## 1.0.0 — 11.11.2026 — первый полноценный релиз
- **Программа передач** для главных каналов России и Беларуси: «Сейчас / Далее» на карточках и в плеере, программа на сегодня-завтра (📋). Обновляется каждый день (`tools/build_epg.py`).
- **Перемотка эфира** назад («−30», «В эфир») — там, где трансляция хранит последние минуты.
- **Следующая серия / видео** — автоматически через 5 секунд (можно отменить или выключить).
- **Родительский контроль:** детский режим с PIN — только детские каналы, мультфильмы, строгий поиск.
- **Крупный текст** (115 % и 130 %).
- **Перенос избранного и настроек** на другое устройство — кодом или файлом, без регистрации.
- **Голосовой поиск:** Android, Android TV, Chrome, Edge, Safari.
- Программа для ПК: Electron 45 (исправленная ветка), максимальное сжатие.
- Журнал: `docs/devlog/11-release-1.0.0.md`.

## 0.3.0 — 11.11.2026 — глобальное обновление
- **Фильмы и видео снова работают:** публичные зеркала YouTube закрылись (отсюда «HTTP 500» и «таймаут»). Теперь — **официальный плеер YouTube** на новых устройствах и **своё зеркало** на старых; приложение выбирает само по устройству (Настройки → «Источник видео»). Подборки официальных каналов без ключа, поиск/тренды/рубрики — с бесплатным ключом YouTube API пользователя ([docs/YOUTUBE.md](docs/YOUTUBE.md)).
- **Новинки:** «🆕 Новинки кино — трейлеры и премьеры» (Central Partnership, Кинопоиск, Netflix, Universal, Disney), «🧸 Новые мультфильмы», «🌸 Аниме» (Muse Asia, Crunchyroll, Aniplex, GKIDS); новые жанры фильмов: аниме, триллер, фэнтези, семейные, исторические, биография, мюзикл, спорт, сериалы.
- **Приложение знает возможности устройства:** кодеки H.264/HEVC/VP9/AV1, HLS, WebM/MKV, лучшее качество — Настройки → «Ваше устройство»; по ним выбираются источник YouTube и файлы с ПК.
- **Везде одно приложение:** программа для **Windows** (установщик и переносная) и **Linux** (AppImage); веб-приложение **PWA** (установка из браузера, работает без интернета); страница установки, которая сама определяет устройство ([docs/DESKTOP.md](docs/DESKTOP.md)).
- **Дизайн:** новая собственная иконка, градиенты, скругления, плавные переходы; **нет синей обводки** при нажатии на вкладки (рамка фокуса — только при управлении с клавиатуры и пульта).
- **Безопасность:** Content Security Policy; проверка команд мостов iOS/Android/ПК (только http/https, лимиты, только главный фрейм); проверка скачанного каталога; Electron в песочнице с Fuses; CI — действия по хэшам, CodeQL, Dependabot, подтверждение сборки и SHA256SUMS у релизов ([SECURITY.md](SECURITY.md)).
- **Право:** [docs/AUDIT.md](docs/AUDIT.md) — предварительный аудит (РФ, РБ, GDPR, CCPA, LGPD, PIPL, App Store, Google Play, OWASP MASVS, риски, план 7/30/90 дней); [docs/PRIVACY.md](docs/PRIVACY.md); запрещённый контент и отсутствие плагиата — [docs/LEGAL.md](docs/LEGAL.md), раздел 10.
- **Репозиторий очищен:** только свежая версия, старая история и архивные файлы хранятся у разработчика.
- Журнал: `docs/devlog/10-official-youtube-desktop-security.md`.

- **Сертификаты:** добавлен корень Sectigo R46 (CDN jsDelivr для обновления каталога).
- **Правовое:** разбор в `docs/LEGAL.md`; вкладка YouTube переименована в «Видео» с оговоркой и выключателем; советские фильмы — только с официальных каналов «Мосфильма», «Союзмультфильма», «Беларусьфильма» (полка с archive.org убрана); **безопасный режим** (по умолчанию) скрывает источники, признанные нежелательными в РФ / экстремистскими в РБ («Дождь», «Настоящее Время» и др.); приложена лицензия hls.js; раздел «Правовая информация» в Помощи.

## 0.2.0 — 09.11.2026 (старый номер 2.0.0)
Полная пересборка: из «плеера каналов» — в приложение для любой техники.

- **Архитектура:** общий веб-интерфейс `web/` (ES5, без фреймворков) для iPad, Android, Smart TV и ПК + нативная iOS-оболочка (WKWebView + мост). Документация в `docs/`.
- **Вкладки:** ТВ, Поиск, YouTube, Фильмы, Избранное, Ещё.
- **Каналы:** Россия и Беларусь — основные (порядок как в эфирном пакете, номера для пульта); 16 стран и 6 подборок «Мир» — в «Дополнительно». Названия на кириллице. 1753 канала.
- **Нерабочие каналы:** проверка каждой ссылки «как iPad» (`tools/check_streams.py`), статусы на карточках, «только рабочие», раздел «Не работают»; плеер перебирает резервные источники и запоминает, что работает на устройстве.
- **Медленная загрузка:** таймаут на источник, сразу переход к резервному, лучшие источники первыми; hls.js в лёгком режиме стартует с низкого качества; корневые сертификаты Let's Encrypt для iOS 9–10 (главная причина «вечной загрузки»).
- **Поиск как на YouTube:** подсказки, история, результаты по каналам, видео, эфирам, YouTube-каналам и фильмам; транслит и поиск по категории.
- **YouTube:** эфиры, тренды, подборки, подписки — через Invidious/Piped с автовыбором зеркала.
- **Фильмы:** архив кино (archive.org), свои ссылки, M3U-плейлисты, фильмы с ПК по Wi‑Fi (`tools/serve.py`), «продолжить с места».
- **Старая техника:** автоматический лёгкий режим, управление пультом/клавиатурой.
- **Каталог без переустановки:** «Обновить список каналов», еженедельное обновление в GitHub Actions.
- **GitHub:** лицензия MIT, CI: сборка `TV.ipa`, обновление каталога, GitHub Pages.
- Код v1.0 сохранён в `ios/legacy/main_v1.m`, сборка v1.0 — `releases/TV-1.0.ipa`.
