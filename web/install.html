BridgeTV

Телеканалы, видео и фильмы — одно приложение для телефона, планшета, компьютера и телевизора. Выберите своё устройство (подходящее отмечено автоматически).

Установить прямо из браузера быстро

Приложение появится на рабочем столе / экране «Домой» и будет открываться отдельным окном.

Windows 10 / 11

Программа для ПК. Установщик или переносная версия (запускается без установки, например с флешки).

Скачать установщик Переносная версия

Программа пока без цифровой подписи: Windows может показать «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

Linux

Файл AppImage: скачать, разрешить запуск (chmod +x BridgeTV-linux.AppImage) и открыть.

Скачать AppImage

macOS

Откройте веб-версию в Safari → меню «Файл» → «Добавить в Dock» (macOS 14+). В Chrome — значок установки в адресной строке.

Открыть веб-версию

Android, Android TV (4.4 и новее)

Скачайте файл и откройте его. Если телефон спросит — разрешите установку из этого источника.

Скачать BridgeTV.apk

iPhone, iPad (iOS 9 и новее)

Без установки файлов: откройте веб-версию в Safari → «Поделиться» → «На экран «Домой»». Работает на любой версии iOS.

Открыть веб-версию

Отдельное приложение (.ipa): ставится через AltStore / Sideloadly / TrollStore или на устройство с джейлбрейком — подробнее в инструкции.

Скачать BridgeTV.ipa

Smart TV

Samsung (Tizen), LG (webOS) — пакеты в разделе релизов; установка через режим разработчика. Любой телевизор с браузером — просто откройте веб-версию.

Безопасность

Скачивайте BridgeTV только отсюда или со страницы проекта на GitHub. У каждого релиза есть файл SHA256SUMS.txt с контрольными суммами и подтверждение сборки GitHub (attestation): файлы собраны автоматически из открытого исходного кода.
